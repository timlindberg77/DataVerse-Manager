# Grupp-Project-NeuralNinjas

Projektidé
Vi vill analysera arbetsmarknaden i Göteborgs Stad fram till år 2030 för att undersöka vilka yrken och branscher som förväntas ha störst behov av arbetskraft.
Syfte

Syftet är att göra det enklare för människor att förstå hur arbetsmarknaden i Göteborg kan förändras fram till 2030. Genom att samla och analysera statistik och framtidsprognoser vill vi visa vilka yrken som kan bli mer efterfrågade och hjälpa människor att fatta mer informerade beslut om utbildning och framtida yrkesval.
